# Aside · Apple 风格版（设计 MVP）

一份**只用来看前端设计**的原型。数据是内置的假数据，不落盘、不同步、不导出。

> 原版 `~/shelvee_master/aside/` **一个字节都没动**。这是平行的第二个目录，
> 看过之后再决定要不要接真实数据、要不要往下做。

## 怎么看

```bash
cd ~/shelvee_master/aside-apple && python3 -m http.server 8080
```

然后用 **iPhone Safari** 访问 `http://<Mac的IP>:8080`。

毛玻璃材质、安全区、大标题折叠这三样在桌面浏览器上看不准，**一定要用手机看**。
桌面双击 `index.html` 也能打开，但只能看排版和上下文菜单。

想看得更像 App：在 Safari 里「添加到主屏幕」，以独立 PWA 模式再走一遍。

## 逐项对照着看

| 看什么 | 怎么触发 | 对比原版 |
|---|---|---|
| 大标题折叠 | 打开就在底部（=今天），大标题亮着；往上翻进历史，它收进顶栏中间的小标题 | 原版印的是 App 自己的名字 `Aside` + `共 137 条` |
| 导航图标 | 右上角三枚 | 原版是 38px 圆形填充底片（Material 做法），且描边 1.9/1.9/1.8 三种粗细 |
| 日期条吸顶 | 往上翻，日期条钉在顶上，下一天把上一天顶走 | 原版滚上去就没了 |
| 正文字号 | 气泡正文 17px（iOS Body） | 原版 15.5px |
| 输入框缩放 | 点输入框**不再自动放大页面**，且双指可以缩放 | 原版为了压住自动放大，直接禁用了缩放 |
| 筛选计数 | 数字退成尾随的次级色小字 | 原版和标签名同字号同颜色 |
| 空状态 | 切到「摘抄」，长按那条唯一的摘抄 → 删除 | 原版是 14px 三级灰、顶上压 60px |
| **上下文菜单** | **长按任意气泡** | 原版是从屏幕底部升起一张操作表 |
| 气泡入场 | 输入框打点字发送 | 原版是闪现 |
| 待办 | 双击气泡转待办，点圆圈勾掉 | 勾的描画动画是新的 |
| 横滑 | 气泡上左右滑：没到那边就挪过去，已经在那边就切高光 | 与原版规则一致，常量照搬 |

### 上下文菜单要看的四件事

1. **长按屏幕上半部的气泡** → 菜单向下开；**长按最底下那条** → 菜单向上开
2. **长按左边（往日）的气泡** → 菜单左对齐；**右边（今天）的** → 右对齐
3. 顶部那行四个图标 = 高光 / 摘抄 / 置顶 / 隐藏。**点开点关，气泡样式实时跟着变**，
   菜单不关闭 —— 开/关从「读文字判断」变成「看填色判断」
4. 背景虚化，被按的气泡浮起来；**列表本身不动**（浮起来的是它的克隆体，滚动位置不丢）

原版长按菜单一二组共 12 行，超过 iOS 上下文菜单开始滚动的高度。
苹果的解法不是删功能，而是把一组互斥可见的开关压成顶部图标行（Messages 的 tapback 行）。
**12 行 → 1 行图标 + 9 行，一个功能都没少。**

## 内置了什么假数据

15 条铺在 3 天上，把每种气泡形态都占满：

```
3天前  普通 · 普通 · 高光(黄) · 摘抄(左竖线)
昨天   普通 · 普通 · 待办未勾 · 多图叠 · 置顶(顶部横幅) · 隐藏(糊掉)
今天   普通 · 带回复引用 · 单图 · 待办已勾 · 待办未勾
```

图片是内联 SVG 渐变块，不碰 IndexedDB。

## 这版**没做**什么

localStorage 持久化 · 云同步 · Markdown 导出 · 真实图片 · 标签自动识别 ·
设置页 · 日历页 · 深色模式 · Service Worker

顶栏三枚图标、加号、以及菜单里的「回复/多选/编辑/标签/时间」点了只弹提示条 ——
这一轮要回答的是「这套设计对不对」，不是「功能全不全」，上面这些都不改变一个像素。

深色模式是**明确单开一轮**的，不在本次范围内。

## 已经验证过的

- 16 项交互冒烟测试全过（标记就地生效、待办、发送入场、删除、筛选、空状态、分组）
- 无横向溢出；无 JS 报错
- 上下文菜单的上开/下开/左对齐/右对齐/空间不够时顶起气泡，四种摆位都对
- `prefers-reduced-motion` 下动画全部降级

只在桌面 Chrome（500px 视口起）验证过 —— **手机上的实机观感还没验，那正是要你看的**。
